> A graph nobody else can read isn't finished, whatever it renders.

## What to do

Rebuild this course's supplied graph across all four tiers from this
week's exercise, on one held-constant shot: the bare graph as a
baseline, the graph plus reference anchoring, the graph plus an upscale
and fix pass, and finally a two-stage pipeline that generates a keyframe
in one graph and hands it to a second graph that turns it into video.

## What to submit

All four graph files, each one's output, and a short note naming which
of the four node jobs — loader, conditioning, sampler, fix pass — each
addition between tiers is doing.

## How it's assessed

Graph legibility checks whether the note correctly names each addition's
job, and whether someone other than its author could follow the graph
file cold. Editing judgment checks that each tier is a genuine edit of
what came before it, not a rebuild from an empty graph each time.
Range across the pipeline checks that the two-stage top tier actually
demonstrates a keyframe handed into a second, distinct graph, not the
same graph run twice.
