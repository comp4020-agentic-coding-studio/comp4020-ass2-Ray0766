## States, not transitions

"The rival arrives uninvited" is a state a shot can show. "Then things get
tense" is a feeling, and leaves the storyboard guessing.

<LadderStill week={9} tier="t2" />

```notes
A beat sheet works best written as a sequence of states — what is true at
this point in the story — rather than a sequence of transitions describing
how one moment turns into the next. "The rival arrives uninvited" is a state;
"then things get tense" is a transition describing a feeling rather than
naming anything a shot could show. A beat sheet written entirely in states
gives a storyboard something concrete to draw; one written in transitions
leaves the storyboard guessing at what actually needs to be on screen.
```

## The three-second hook

A vertical episode is watched thumb-first, and the default action is to keep
scrolling. The opening shot has about three seconds.

```notes
A vertical episode is watched thumb-first, and a viewer's default action is
to keep scrolling: the opening shot has roughly three seconds to give them a
reason not to.
```

---

## Pick one device on purpose

Mystery, conflict in progress, visual anomaly, or direct address. A shot
trying to be all four earns none of them.

```notes
A cold open reliably uses one of four devices: a mystery hook showing a
consequence without its cause, a conflict-in-progress hook starting
mid-argument, a visual-anomaly hook putting something wrong in frame before
anything explains it, or a direct-address hook speaking straight to camera.
Pick one on purpose — a shot trying to be all four earns none of them, and
the hook is the first state on the beat sheet, not an afterthought bolted
onto it.
```

## The storyboard as a shot list

Every entry names a size and the reference it checks against. A board without
its references is a set of pictures, not a production document.

<LadderStill week={9} tier="t4" />

```notes
A storyboard for this course is not a drawing exercise; it's a shot list with
a size and a reference attached to each entry — which reference sheet or
master plate that shot checks against, and roughly how close the frame is. A
board that only shows composition without naming its reference is a set of
pictures, not a production document; whoever shoots from it later needs to
know which locked asset each panel is supposed to match.
```

## The ladder

The same two-to-three-shot sequence, four ways.

1. A prose paragraph, with no shot breakdown at all
2. That paragraph as a beat sheet written in states
3. Plus a shot list, with a size named for every shot
4. Boarded with keyframes, each tagged to the reference it must match

```notes
The ladder this week runs four tiers, each covering the same
two-to-three-shot sequence. The lowest tier is a prose paragraph describing
what happens, with no shot breakdown at all. The next tier turns that
paragraph into a beat sheet written in states. The next tier adds a shot list
to the beat sheet, with a size named for every shot. The top tier boards the
sequence with actual keyframes, each one tagged with the reference material
it has to match.
```
