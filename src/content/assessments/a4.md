> One dial, five inputs, and nothing else allowed to move.

## What to do

Take one input through the five-tier turnaround ladder from this week's
exercise — rough sketch, clean lineart, flat colour, finished keyframe,
finished keyframe under ControlNet — running the same prompt and the
same denoising strength across every tier. The strength and prompt stay
fixed on purpose: what changes is only how finished the input already
is.

## What to submit

The turnaround sheet: all five outputs in ladder order, the shared
prompt, the strength value used, and a seed and parameter log covering
every tier.

## How it's assessed

Strength discipline checks that the same strength value was actually
used across all five tiers, not quietly adjusted to flatter a weaker
input. Input-to-output logic checks whether more finish in the input
visibly bought more control in the output, tier by tier. Log quality
checks that the log reproduces any single tier without anyone
explaining it aloud.
